### 🧠 What I Build

| Capability | What it means |
|---|---|
| **Agentic RAG** | Hybrid retrieval, cross-encoder reranking and metadata filtering over your own knowledge base |
| **Multi-Agent Orchestration** | Stateful, tool-calling agents that plan, act and hold context across long-running workflows |
| **LLM Application Backends** | Typed APIs, structured outputs, streaming and schema validation wrapped around the model layer |
| **Document Intelligence** | OCR and layout-aware parsing that turns unstructured documents into clean, queryable data |

Every system ships with cost controls, schema validation and a human in the loop,
because a demo that impresses is not the same as one you can run on Monday.
